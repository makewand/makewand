创建一个个人费用追踪看板:
- 后端: FastAPI + SQLite
  - RESTful API: 增删改查费用记录
  - 字段: 金额, 分类(餐饮/交通/购物/娱乐/其他), 日期, 备注
  - 统计接口: 按月汇总, 按分类汇总, 趋势数据
- 前端: React + Tailwind CSS + Recharts
  - 添加/编辑/删除费用
  - 月度饼图 (按分类)
  - 6个月趋势折线图
  - 费用列表 (支持按日期、分类筛选)
  - 月度预算设置 + 超支警告
- 完整的 package.json, requirements.txt
- 后端有 pytest 测试 (至少覆盖 CRUD)
- 前端有基本组件测试
