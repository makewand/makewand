# 评估补漏修复记录 · 2026-10-01

| 历史项 | 补齐后的行为 | 回归证据 |
|---|---|---|
| R06 探测信任策略 | `probe`、`status --probe`、`quota --probe` 传递 trust 与工作目录；不可信仓库的实时模型探测在进程启动和预算准入前拒绝。可信 echo 与只读版本检查使用独立临时目录；缓存读取仍可使用 | `tests/test_probe_policy_regressions.py` |
| R07 Git 错误与索引 | 差异读取使用临时索引和固定提交对象；损坏 HEAD、暂存失败、差异失败及属性屏蔽失败明确报错。真实未提交索引和锁文件保持原样；候选清单展开未跟踪目录中的实际文件 | `tests/test_git_diff_fail_closed.py`、交付与 hybrid 回归 |
