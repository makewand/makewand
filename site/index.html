为专业开发者打造的下一代 AI 编排体系

告别单一模型视野盲区与昂贵 API 账单，榨干本地所有可用 AI 订阅能力。

⚡

自适应动态拓扑引擎

开箱即检。提供 1 个工具则启动 Shadow Worktree 独立批判自省；提供 2 个及以上工具则自动组建异构互审网络， 从 0 到 15+ 工具全平滑缩放，永不硬编码限制。

💰

零额外 Token 订阅复用

直接复用您已开通的 Google AI Pro、Claude Max、Codex Pro 等官方专业订阅， 直接驱动本地 CLI 子进程，摆脱昂贵的商业 API 转发中介。

🛡️

物理隔离红队独立盲审

Primary 编码模型与 Review 审查模型在上下文和思维树上严格物理隔离，审查者只看 Git Diff 与代码逻辑， 彻底斩断“自写自测、自我圆谎”的思维盲区。

🌿

Git Worktree 沙箱防踩踏

所有改动在独立的临时 Git Worktree 中进行单测与验证，不碰主工作区未提交代码； 多会话并发执行与宿主机负载背压自适应控制，杜绝代码踩踏。

🔄

配额治理与自愈降级回环

实时感知各模型 24 小时配额消耗与限流状态（429）。遇到额度告罄自动降级至备选健康模型无缝接管， 保障长时间无人值守任务（/goal）稳定闭环。

🏢

企业级多租户与 Web 控制台

内置 OpenAI 兼容网关与 Web 管理后台（Playground、Token 配额鉴权、团队组织计费、审计日志）， 支持 Docker、Systemd 与 Cloudflare Tunnel 一键部署。
